# Portfolio - Kristin Bodvarsdottir

A modern, responsive portfolio website showcasing both front-end development skills and analytical capabilities through interactive data visualizations.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations and gradient effects
- **Interactive Navigation**: Smooth scroll navigation for easy access to all sections
- **Skills Showcase**: Comprehensive display of technical skills organized by category
- **Project Portfolio**: Featured projects highlighting both front-end and analytical work
- **Data Visualizations**: Interactive charts powered by Chart.js demonstrating analytical skills
  - Skills proficiency bar chart
  - Project timeline line graph
  - Technology distribution doughnut chart
- **Contact Section**: Easy ways to get in touch with direct links

## 🛠️ Technologies Used

### Front-End
- **React 18**: Modern React with hooks for component-based architecture
- **CSS3**: Custom styling with gradients, animations, and responsive design
- **HTML5**: Semantic markup for accessibility

### Data Visualization
- **Chart.js 4**: Professional charting library for interactive visualizations
- **react-chartjs-2**: React wrapper for Chart.js integration

### Development Tools
- **Create React App**: Bootstrap and development environment
- **npm**: Package management

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/bodvarsdottirkristin/portfolio-kb.git
cd portfolio-kb
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Building for Production

To create a production build:
```bash
npm run build
```

This creates an optimized build in the `build` folder ready for deployment.
